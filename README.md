# Pranam Agro Foods Homepage Interface

A modern ecommerce-style static homepage built with normal HTML, CSS and jQuery-ready JavaScript.

## Files
- `index.html` — homepage structure
- `style.css` — responsive ecommerce UI styling
- `script.js` — jQuery menu, wishlist and add-to-cart interactions

## How to run
Open `index.html` in a browser, or deploy the folder to Vercel as a static site.
